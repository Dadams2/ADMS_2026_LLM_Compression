\section{Conclusion}

\begin{frame}{Key Takeaways}
  \begin{enumerate}
    \item \textbf{LLMs can compress text very well.} Ratios above $7\times$ on natural language and $11\times$ on code are possible in these experiments.

    \vspace{0.45em}
    \item \textbf{The implementation determines the economics.} For a fixed model, throughput varies dramatically with logit access and entropy-coding design.

    \vspace{0.45em}
    \item \textbf{Target-interval capture is the strongest optimization.} It turns dense score processing into a constant-size per-token record.

    \vspace{0.45em}
    \item \textbf{There is still systems headroom.} Current engines are not optimized for score extraction, and CPU SIMD paths remain underexplored.
  \end{enumerate}
\end{frame}
